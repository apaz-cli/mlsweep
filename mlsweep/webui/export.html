The manager uploads each run to W&B. A run's sweep parameters become its config, its experiment becomes its group, and its campaign becomes a tag.

wandb is not installed where the manager runs. Install it there with pip install 'mlsweep[wandb]' and restart the manager.
Leave blank to use the manager's WANDB_API_KEY or its saved wandb login. The key is not stored, but it is sent in the request; use HTTPS if the dashboard is remote.
